## What's New & Changed

### Highlights
- **Cross-Platform Desktop Releases**: Native builds for Windows (x64 Installer & Portable), macOS Apple Silicon (`arm64`), macOS Intel (`x64`), and Linux (`AppImage` & `.deb`).
- **Independent Multi-List NDI® Broadcast Output**: Stream each timer list tab as its own dedicated NDI network video source with clean stream names and independent state synchronization.
- **Global Keyboard Shortcuts Manager**: Trigger Start/Pause, Reset, Next/Previous timer, and tab switching without leaving your production workflow.
- **Reusable List Templates**: Save any cue list as a template or instantly load built-in presets (Sunday Service, Sports, Conference, and more) in the New Timer workflow.
- **GitHub Auto-Updater**: Reliable one-click **Check for Updates** and automatic installer updates via GitHub Releases (`latest.yml`, `latest-mac.yml`, `latest-linux.yml`).
- **Refined Launch Experience & Tab Controls**: Extended animated ProTimer launch splash and full right-click tab context menu (Edit, Rename, Save as Template, Delete).

## Upgrading & Auto-Updates

- **Windows Installer (`Setup.exe`) & Linux (`AppImage`)**: Open **Help → Check for Updates** (or **Settings → Updates**) inside ProTimer to download and install new releases automatically.
- **Windows Portable / macOS (`.dmg` / `.zip`) / Linux (`.deb`)**: ProTimer notifies you as soon as a new release is available and lets you download the matching installer directly from GitHub Releases.
- **macOS First Launch Note**: Because macOS builds are currently ad-hoc signed, if Gatekeeper warns on first launch, right-click `ProTimer.app` → **Open** (or allow it under **System Settings → Privacy & Security**).
