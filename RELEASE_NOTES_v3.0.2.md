## Upgrading & Auto-Updates

- **Windows Installer (`Setup.exe`) & Linux (`AppImage`)**: Open **Help → Check for Updates** (or **Settings → Updates**) inside ProTimer to download and install new releases automatically.
- **Windows Portable / macOS (`.dmg` / `.zip`) / Linux (`.deb`)**: ProTimer notifies you as soon as a new release is available and lets you download the matching installer directly from GitHub Releases.
- **macOS First Launch Note**: Because macOS builds are currently ad-hoc signed, if Gatekeeper warns on first launch, right-click `ProTimer.app` → **Open** (or allow it under **System Settings → Privacy & Security**).
